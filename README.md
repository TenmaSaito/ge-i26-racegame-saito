# racegame

鈴鹿サーキットなどを走る、3D レースゲームです。AI の対戦相手（最大 3 台、強さは 3 段階）と競うことも、1 人でタイムアタックすることもできます。ドリフト実装済みです（下記「ドリフト」参照）。

コースの線形は OpenStreetMap（relation 284570、Suzuka International Racing Course）、高さは国土地理院の標高タイルです。

- 地図データ: © OpenStreetMap contributors
- 標高: 出典 国土地理院

画像は `assets/graphics/`、音声は `assets/sound/` に置きます。コースデータは `assets/track/` です。

## コース

3 コースあります。既定は鈴鹿です。

- `suzuka` — 鈴鹿サーキット（実在コース、全長 5,793m）
- `flow` — Flow Circuit（全長 3,646m）。今の車のドリフトに合わせて設計したオリジナルコースです。道幅 10m・ランオフ 16m と広く、大きめのスイーパーと S 字のチェーン区間を中心に、滑りながら走り切る気持ちよさを優先しています。ヘアピンが 1 つあります。レイアウトは `tools/generate_flow_course.py`（制御点スプライン）で生成していて、制御点を動かして再実行すればコースを作り直せます。
- `coast` — Coast Circuit（全長 4,010m）。参考動画のような疾走感を狙ったオリジナルコースです。約 800m と 600m の直線を高速スイーパーでつなぎ、中速ベンドとヘアピン（R31m）を織り交ぜています。道幅 9m・ランオフ 3.5m と壁が路傍に近く、流れていく壁と木が速度感を出します。レイアウトは `tools/generate_coast_course.py` で生成します。

切り替えは、ネイティブ版は引数 `--track coast`、ブラウザ版は URL の `?track=coast` です（例: `racegame.html?track=coast`）。

全コース共通で、路傍には木が並び（壁の外側、約 14m 間隔）、ドリフト中は後輪からタイヤ煙が出ます。

## 開き方

Cursor または VS Code でこのフォルダを開き、**Reopen in Container** を選びます。初回はイメージのビルドに数分かかります。

## 操作

キーボードとゲームパッドは、一般的な 3D レースゲームと同じです。ドリフト用にハンドブレーキ相当のボタンと、ゲームパッドの右スティック（ツインスティック）があります。

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| アクセル | W / ↑ | RT（R2）。十字キー上でも可 |
| ブレーキ / 後退 | S / ↓ | LT（L2）。十字キー下でも可 |
| ステアリング | A D / ← → | 左スティック、十字キー左右 |
| ドリフト | Space / Shift / Ctrl（押しながらステア）。または A/D（ステア）+ ←/→（ドリフトスティック）のキーボード・ツインスティック | B（○）/ LB / RB（押しながら左スティック）、または右スティック左右 |
| リスタート | R | Back（View / Share） |
| カメラ | C | Y（△） |
| ポーズ | P | Start（Menu / Options） |
| 操作表示 | H | |
| ドリフトデバッグ表示 | B | |
| ドリフト調整パネル | T（開いたら ↑↓ で選択、←/→ で調整、Shift 同時押しで大きく） | |
| マウス操作 | ドリフト中に、開始位置から横にずらす＝ドリフトを強める/弱める（車体の操作はしません） | |

マウスはハンドルではなく、ドリフトの強さを調整するダイヤルとして働きます。ドリフトが始まった瞬間のマウス位置が原点として保存され、そこから横にずらした分だけ、いまの操作に上乗せしてドリフトが強まります（フルになるのはウィンドウ幅の 25% ぶん動かしたとき）。原点に戻せば上乗せは消え、逆向きにずらせばカウンターとしてドリフトを弱めます。約 20px の小さなデッドゾーンから比例して効くので、「効かない→突然効く」という跳ねはありません。マウスだけでドリフトを始めることはできませんが、ドリフト中にずらしたまま保持すれば、キーやスティックを離しても角度を保てます。ドリフトしていない間、マウスは車に何もしません。

画面は追従、近め、遠めの 3 つです。ギアは 6 速オートマで、右下にギアと回転数（タコメーター）を表示します。

## 対戦相手 (AI)

タイトルの次の「RACE SETUP」画面で、↑↓ で項目を選び ←→ で値を変えます。

| 項目 | 内容 |
|---|---|
| STAGE | コース |
| TIME | 昼（DAY）/ 夜（NIGHT） |
| CAR | 車種（対戦相手も同じ車種。性能差ではなく腕の勝負） |
| LAPS | 周回数。1 / 2 / 3 / 5 / 10 周、または FREE RUN（周回無制限。ゴールせず好きなだけ走れる） |
| RIVALS | 対戦相手の数。SOLO（1 人でタイムアタック）/ 1〜3 台 |
| AI LEVEL | 強さ。EASY / NORMAL / HARD |

- AI はプレイヤーと同じ物理で走ります。コースの曲がり具合から速度を計画し（ブレーキが間に合う速度まで手前から逆算）、先の目標点を狙ってハンドルを切ります。前に車がいれば空いている側へラインをずらして抜きにかかります。車同士はぶつかると押し合います。
- AI もドリフトします。低中速のきついコーナー（ヘアピンやシケインなど）が近づくと、コーナーごとに「ドリフトで行くか」を決め、プレイヤーと同じドリフトボタン＋ステアで滑らせます。滑っている間は進んでいる向きで狙いを付け、抜けるときは角度を消してからボタンを離します。積極性は強さで変わり、EASY は派手に滑りがち、HARD は要所だけで滑ります。
- 強さはコーナーで攻める度合い・ブレーキの深さ・ハンドルのぶれ・ドリフトの積極性で変わります。AI 単独で鈴鹿を 1 周すると、およそ EASY 137 秒 / NORMAL 119 秒 / HARD 105 秒です。
- レース中は左側に順位（`P2/4`）と順位表（対戦相手は車の色で表示）が出ます。リザルトには最終順位が出ます。
- 周回数を決めたレースは、規定周回でゴールするとリザルト（タイム・順位・ランキング）が出ます。**Enter でタイトルへ戻り**、R で同じ設定のままもう一度走れます。FREE RUN はゴールが無いので、ポーズ（P / Esc）中に T でタイトルへ戻ります。ランキングはコースと周回数ごとに別です。

## 夜

TIME を NIGHT にすると、同じコースを夜に走ります。

- 空と遠景は暗い紺になり、月明かりがうっすら当たります。
- 自分と対戦相手の車はヘッドライトを点け、前方の路面を照らします（各車のライトが路面に落ちるので、後ろから来る車も光で分かります）。テールランプも常に点灯します。
- バックミラーは夜は明るさを上げて映すので、後ろの対戦相手（ヘッドライトとボディ）や、ゴースト（過去の自分。夜は青白く光る）が見えやすくなっています。
- これまでに戦った対戦相手の人数（名前が違う相手を 1 人と数える）と勝利数を、タイトル・設定・リザルトの各画面に `OPPONENTS FACED` として表示します。

## 走行記録と学習

ゴールするたびに走行記録（名前・タイム・コースを 100 区間に分けた区間ごとの速度）を残し、AI がそれを使って学習します。

- **速度の学習**: 速い記録の区間速度を平均し、AI の目標速度に混ぜます（強さに応じて 30〜90%）。人が実際に速く走れている区間では AI も攻めます。
- **相手のモデル化**: オンラインで共有されたほかの人の記録のうち、自分に近い速さの人の走りを真似る AI が、その人の名前で出走します。
- **強さの調整**: 勝てばその難易度の AI は少し速く、最下位なら少し遅くなります（±8% まで）。

記録はブラウザ（localStorage）やネイティブ版の設定ファイルに保存され、オフラインでも学習に使われます。プレイヤー名はページのゲーム画面の下の入力欄で設定します（ネイティブ版は `--name 名前`）。

### オンライン共有（無料）

記録は Cloudflare Workers + KV の無料枠で動く小さなサーバー（`server/`）で共有できます。ゲーム側に鍵は置かず、サーバーが記録の妥当性を検証し、連投を制限します。公開の手順・安全の設計は [server/README.md](server/README.md)、しくみは [docs/ONLINE.md](docs/ONLINE.md) にあります。公開した URL をページの `window.RACEGAME_API` に書くと有効になります（空なら手元だけで動きます）。

動作確認用に、URL に `?autopilot=1`（ネイティブ版は `--autopilot`）を付けると、プレイヤーの車も AI が運転します。

## スタートシグナル

レース開始時は画面上部（バックミラーの下）にスタートシグナルが出ます。3・2・1 に合わせて赤ランプが左から 1 灯ずつ点き（点いた瞬間に光が広がります）、GO で 3 灯すべてが緑に変わってからフェードアウトします。ランプの点灯と同時に電子音（3・2・1 は低い音、GO は 1 オクターブ高い長い音）が鳴り、ゲームパッドも振動します。

## 音

音はすべてゲーム内で作っています。エンジン音だけ素材（`assets/sound/engine.wav`）を加工して使い、ドリフト音は素材を使わずに合成しています。

- **エンジン音**: 速度とアクセルから 6 速オートマの回転数を計算し（`EngineSim`）、録音ループを回転数に比例した速さで読み出して音程を連続的に変えます（段階的な切り替えはありません）。アクセルを踏むほど音が明るく大きくなり、離すと高回転でもこもった音になります。回転数に同期した燃焼音を重ねて低回転の厚みを出しています。シフトアップでは一瞬アクセルが抜けて回転が落ち、カウントダウン中の空ぶかしではレブリミッターに当たって回転が跳ねます。ドリフト中に踏むと後輪の空転で回転が上がります。
- **ドリフト音（合成）**: タイヤのゴムが路面に「張り付く→滑る」を細かく繰り返して鳴る音を、3 つの層で合成しています。(1) 鳴き: 0.5〜1kHz の倍音で、音程がランダムにゆっくり揺れ、20〜50Hz の細かい断続が入る。(2) 擦れ: 鳴きより高い帯域のノイズ（シャー）。(3) ザラつき: 低域のノイズ（路面を擦るゴロゴロ）。ループ素材が無いので、何秒滑っても同じ音の繰り返しになりません。
  - 深さ: 浅い滑りは小さく高めでチリチリと途切れ、深くなるほど急に大きく、低く太い音になります（軽い横滑りで鳴りっぱなしにならない）。
  - 速度: 速いほど高く大きい。持続: 滑り始めは鋭く高め、長く滑るとタイヤが熱を持ったように低めで擦れの多い音になります。
  - 音量はエンジン音より一歩引いた大きさにしてあり（全開のエンジン音の約 4 割）、立ち上がり・消え際は滑らかです。
- **ブラウザ**: ブラウザは操作があるまで音を出さないため、最初のクリック・キー・タッチ・ゲームパッドのボタンで自動的に音が出ます（まだ音が出せない間は画面に `CLICK OR PRESS ANY KEY FOR SOUND` と表示）。タブを裏に回すと音は止まり、戻ると再開します。

音作りの数値は `src/domain/sound/soundmixer.cpp`（音程の幅・音量の配分・時定数）と `src/app/vehicle/enginesim.cpp`（ギア比・シフトの回転数）の先頭にまとめてあります。ゲームを起動せずに音を確認するには、走行の台本を鳴らして WAV に書き出すツールを使います:

```bash
cmake --build build-native --target sounddemo
./build-native/sounddemo assets/sound sound_demo.wav
```

## コードの構成

依存は「外側 → 内側」の一方向だけです。SDL・OpenGL・Emscripten が現れるのは `src/platform/` だけで、それより内側はどのプラットフォームでも同じコードです。

| 層 | フォルダ | 内容 |
|---|---|---|
| ドメイン | `src/domain/` | 車の物理・コース・景観・調整値・**音の合成（sound）**。標準ライブラリのみに依存 |
| アプリケーション | `src/app/` | ゲーム進行（Game）・シーン・HUD・カメラ・演出・周回計測・**エンジン回転数（EngineSim）**・**AI（AiDriver）**・**走行記録と学習（RecordBook）** |
| ポート | `src/ports/` | 外側へ求める能力の宣言（描画 IRenderer・入力・**音声 IAudio**・**記録の共有 IRecordService**） |
| プラットフォーム | `src/platform/` | SDL2 による窓・入力・音声デバイス、OpenGL 描画、保存、通信（ブラウザは fetch）、メインループ |

移植の手順は [docs/ANDROID.md](docs/ANDROID.md)（Android）と [docs/WINDOWS.md](docs/WINDOWS.md)（Windows）にあります。

## ドリフト

『Inertial Drift』の考え方を取り入れたドリフトです。本体は `Car::stepDrift`（`src/car.cpp`、旧 `stepGrip` を差し替え）です。

- 速度はスカラーではなくベクトルで持ちます。車体が回っても速度ベクトルはワールドに残る（慣性）ので、進行方向と車体の向きがずれて横滑りします。グリップは「速度の大きさを保ったまま、速度ベクトルの向きを車体前方へ回す」働きとして効かせています（横速度を捨てる方式だとドリフト中に失速しすぎるため）。通常時はこの回転が速いので従来どおり滑らず走り、ドリフト時は回転が遅くなって滑りが続きます。減速は DRIFT DECEL と抗力だけが担うので、ドリフト中も速度が残り、立ち上がりでは横滑り分が前進速度に変換されます。
- きっかけは 2 つです。(1) ドリフトボタンを押しながら切る、(2) 右スティックを倒す（ツインスティック: 左で車体の向き、右で滑らせる向きを決める。キーボードでは A/D + 矢印キーが同じ役割）。大きく切っただけで勝手に滑り始める「自動ドリフト（フリック）」は廃止しました。ドリフトは必ず意図的な入力でのみ始まります。キーボードのようなオン/オフ入力でも角度を保てるよう、ドリフト操作は内部で平滑化しています。
- ドリフト中は横グリップが大きく落ち、ステア／右スティックが目標スリップ角（最大約54度）を決めます。逆に切るカウンターステアで角度を保ったり浅くしたりでき、入力を離すとグリップが戻って収束します。
- 「滑りながら移動する」ための調整も入っています。ドリフト中はステアによる車体の回頭を弱め（角度の主役をドリフト入力に渡す）、駆動力の半分を車体前方ではなく進行方向（速度ベクトルの向き）へ回すので、角度を保ったまま失速せずにコーナーを抜けられます。ドリフト中は後輪からタイヤ煙が出ます。
- 長いカーブ向けに、ドリフトは「粘る」ようになっています。ドリフトボタンを押している間は、必要なステアが小さい場面でもドリフトが途切れず、角度はステア量に比例して増減します（倒した分だけ付く）。目標角には速度連動の上限もあり、高速域では浅めに抑えられるので、速いスイーパーを 1 回のドリフトで流し切れます。入力が一瞬途切れても 0.4 秒は維持されます。
- ドリフト中は画面中央上に大きく `DRIFT ○○ DEG` とスリップ角バー、スコアと継続距離（CHAIN）を表示します（ドリフト判定外でも実際に滑っていれば `SLIDE` 表示）。カメラは車体ではなく進行方向寄りを向き、車体は横荷重で少しロールします。
- ドリフトのデバッグ表示（開発用、既定オフ、B キーで切替）があります。状態（GRIP/DRIFT）、スリップ角、横速度、入力値に加えて、ドリフト操作をしているのに入らないときは理由（速度不足など）も表示します。
- T キーでドリフトのチューニングパネルが開き、その場で値を変えて走りながら調整できます。項目は DRIFT GRIP（ドリフト時の横グリップ、小さいほど滑る）、INERTIA（慣性の強さ、大きいほど速度が向きを保つ）、DRIFT DECEL（ドリフト中の減速率、大きいほど失速する）、MAX SLIP（目標スリップ角の上限）、MIN SPEED（ドリフトに入れる最低速度）、NORMAL GRIP（通常時の横グリップ）、ENTRY（ドリフト進入の鋭さ）です。値は自動保存されます（ネイティブ版は `drift_tuning.txt`、ブラウザ版は localStorage）。
- ENTRY は進入の「性格」です。『Inertial Drift』でも車種ごとに「倒した瞬間に跳ねる車」と「徐々に角度が付く車」が分かれているように、ドリフトの入り方は車ごとに違います。ENTRY を上げるとコマンドの立ち上がり・グリップの抜け・車体を回す力がまとめて鋭くなり（切った瞬間に一気に曲がる）、下げると荷重移動でじわりと入る穏やかな進入になります。既定は 0（最も穏やか。実走フィードバックで「滑りがかなり良くなった」と評価された値）です。
- アクセル、ブレーキ、壁、路面の高さは従来どおり `Car::update` 側です。壁に当たったときは速度ベクトルの外向き成分も消し、強く当たったら速度全体を落とします。接触中に車体と進行方向が大きくずれている場合は車体を進行方向へ少し回して壁に沿わせるので、横向きのまま壁を滑り続けることはありません。

`--self-test` にはドリフトの自己確認（加速→ドリフトで17度以上滑る→離すと収束する）と、音の自己確認（WAV の読み込み・ループの継ぎ目・ミキサーの鳴らし分け・ギアシフト）、AI の自己確認（各強さで 1 周を完走し、強いほど速い）、走行記録と学習の自己確認が含まれます。`--self-test --track flow` のようにコースを指定しての確認もできます。

## Chrome 拡張機能（画面外の調整ツール）

ゲーム内フォントは英数字のみのため、調整ツールの日本語 UI は Chrome 拡張として画面外（ブラウザのツールバー側）に置いています。`extension/` フォルダが本体です。

- 導入: Chrome で `chrome://extensions` を開き、デベロッパーモードを ON にして「パッケージ化されていない拡張機能を読み込む」から、このリポジトリの `extension/` フォルダを選ぶ
- 使い方: ブラウザ版ゲームのタブを開いた状態で、ツールバーの「ドリフト調整」アイコンを開くと、全項目を日本語のスライダーで変更できる
- 仕組み: 拡張はゲームページの `localStorage`（キー `racegameDriftTuning`）を読み書きし、ゲーム側は 0.5 秒ごとに確認して変更を走行中でも取り込む。ゲーム内 T パネルと同じ値・同じ保存先なので、どちらで変えてもよい

## ブラウザ版

```bash
emcmake cmake -B build
cmake --build build
python3 -m http.server 8080
```

`http://localhost:8080/build/racegame.html`

公開用ページ（`web/`）を更新するときは、Release でビルドした `racegame.js` / `racegame.wasm` / `racegame.data` を `web/` と `web/portable/` にコピーします。`web/portable/game.html` は 1 ファイル版（`-DRACEGAME_SINGLE_FILE=ON` でビルドした `racegame.js` をページ内に埋め込んだもの）で、ファイルを直接開いても動きます。

```bash
emcmake cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
emcmake cmake -B build-single -DCMAKE_BUILD_TYPE=Release -DRACEGAME_SINGLE_FILE=ON
cmake --build build-single
```

Visual Studio 2022 と vcpkg（SDL2 / SDL2_image）でビルドできます。手順は [docs/WINDOWS.md](docs/WINDOWS.md) を参照してください。

## Linux 版

```bash
cmake -B build-native
cmake --build build-native
./build-native/racegame
```

画面は `http://localhost:6080`（パスワード `vscode`）です。コンテナには音声デバイスが無いため、コンテナ内では音は鳴りません（`SDL_AUDIODRIVER=dummy` で無音のまま動きます）。

ロジックだけの確認:

```bash
./build-native/racegame --self-test
```
