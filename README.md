# racegame

鈴鹿サーキットを走る、3D レースゲームです。車は 1 台です。ドリフト実装済みです（下記「ドリフト」参照）。

コースの線形は OpenStreetMap（relation 284570、Suzuka International Racing Course）、高さは国土地理院の標高タイルです。

- 地図データ: © OpenStreetMap contributors
- 標高: 出典 国土地理院

画像は `assets/graphics/`、音声は `assets/sound/` に置きます。コースデータは `assets/track/` です。

## コース

2 コースあります。既定は鈴鹿です。

- `suzuka` — 鈴鹿サーキット（実在コース、全長 5,793m）
- `flow` — Flow Circuit（全長 3,646m）。今の車のドリフトに合わせて設計したオリジナルコースです。道幅 10m・ランオフ 16m と広く、大きめのスイーパーと S 字のチェーン区間を中心に、滑りながら走り切る気持ちよさを優先しています。ヘアピンが 1 つあります。レイアウトは `tools/generate_flow_course.py`（制御点スプライン）で生成していて、制御点を動かして再実行すればコースを作り直せます。

切り替えは、ネイティブ版は引数 `--track flow`、ブラウザ版は URL の `?track=flow` です（例: `racegame.html?track=flow`）。

## 開き方

Cursor または VS Code でこのフォルダを開き、**Reopen in Container** を選びます。初回はイメージのビルドに数分かかります。

## 操作

キーボードとゲームパッドは、一般的な 3D レースゲームと同じです。ドリフト用にハンドブレーキ相当のボタンと、ゲームパッドの右スティック（ツインスティック）があります。

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| アクセル | W / ↑ | RT（R2）。十字キー上でも可 |
| ブレーキ / 後退 | S / ↓ | LT（L2）。十字キー下でも可 |
| ステアリング | A D / ← → | 左スティック、十字キー左右 |
| ドリフト | Space / Shift / Ctrl（押しながらステア）。または A/D（ステア）+ ←/→（ドリフトスティック）のキーボード・ツインスティック | B（○）/ LB / RB（押しながら左スティック）、または右スティック左右 |
| リスタート | R | Back（View / Share） |
| カメラ | C | Y（△） |
| ポーズ | P | Start（Menu / Options） |
| 操作表示 | H | |
| ドリフトデバッグ表示 | B | |
| ドリフト調整パネル | T（開いたら ↑↓ で選択、←/→ で調整、Shift 同時押しで大きく） | |
| マウス操作 | ドリフト中に、開始位置から横にずらす＝ドリフトスティック（車体の操作はしません） | |

マウスはハンドルではなく「ドリフト専用スティック」として働きます。ドリフトが始まった瞬間のマウス位置が原点（ニュートラル）として保存され、そこから横にずらした分だけドリフトスティックが倒れたことになります。原点に戻せばドリフトは弱まり、遠ざけるほど強まります（フルに倒れるのはウィンドウ幅の 25% ぶん動かしたとき）。右スティックや矢印キーと同じ入力に合流するので、長いカーブでマウスをずらしたまま保持すれば、角度を保ったままドリフトを続けられます。ドリフトしていない間、マウスは車に何もしません。

画面は追従、近め、遠めの 3 つです。ギアはオートマです。

## ドリフト

『Inertial Drift』の考え方を取り入れたドリフトです。本体は `Car::stepDrift`（`src/car.cpp`、旧 `stepGrip` を差し替え）です。

- 速度はスカラーではなくベクトルで持ちます。車体が回っても速度ベクトルはワールドに残る（慣性）ので、進行方向と車体の向きがずれて横滑りします。グリップは「速度の大きさを保ったまま、速度ベクトルの向きを車体前方へ回す」働きとして効かせています（横速度を捨てる方式だとドリフト中に失速しすぎるため）。通常時はこの回転が速いので従来どおり滑らず走り、ドリフト時は回転が遅くなって滑りが続きます。減速は DRIFT DECEL と抗力だけが担うので、ドリフト中も速度が残り、立ち上がりでは横滑り分が前進速度に変換されます。
- きっかけは 3 つです。(1) ドリフトボタンを押しながら切る、(2) 右スティックを倒す（ツインスティック: 左で車体の向き、右で滑らせる向きを決める。キーボードでは A/D + 矢印キーが同じ役割）、(3) 高速で大きく切りながらアクセルを踏み続けるフリック入力。キーボードのようなオン/オフ入力でも角度を保てるよう、ドリフト操作は内部で平滑化しています。
- ドリフト中は横グリップが大きく落ち、ステア／右スティックが目標スリップ角（最大約54度）を決めます。逆に切るカウンターステアで角度を保ったり浅くしたりでき、入力を離すとグリップが戻って収束します。
- 長いカーブ向けに、ドリフトは「粘る」ようになっています。ドリフトボタンを押している間は、必要なステアが小さい場面でもドリフトが途切れず、角度はステア量に比例して増減します（倒した分だけ付く）。目標角には速度連動の上限もあり、高速域では浅めに抑えられるので、速いスイーパーを 1 回のドリフトで流し切れます。入力が一瞬途切れても 0.4 秒は維持されます。
- ドリフト中は画面中央上に大きく `DRIFT ○○ DEG` とスリップ角バー、スコアと継続距離（CHAIN）を表示します（ドリフト判定外でも実際に滑っていれば `SLIDE` 表示）。カメラは車体ではなく進行方向寄りを向き、車体は横荷重で少しロールします。
- 右上にはドリフトのデバッグ表示（既定オン、B キーで切替）があります。状態（GRIP/DRIFT）、スリップ角、横速度、入力値に加えて、ドリフト操作をしているのに入らないときは理由（速度不足など）も表示します。
- T キーでドリフトのチューニングパネルが開き、その場で値を変えて走りながら調整できます。項目は DRIFT GRIP（ドリフト時の横グリップ、小さいほど滑る）、INERTIA（慣性の強さ、大きいほど速度が向きを保つ）、DRIFT DECEL（ドリフト中の減速率、大きいほど失速する）、MAX SLIP（目標スリップ角の上限）、MIN SPEED（ドリフトに入れる最低速度）、NORMAL GRIP（通常時の横グリップ）、ENTRY（ドリフト進入の鋭さ）です。値は自動保存されます（ネイティブ版は `drift_tuning.txt`、ブラウザ版は localStorage）。
- ENTRY は進入の「性格」です。『Inertial Drift』でも車種ごとに「倒した瞬間に跳ねる車」と「徐々に角度が付く車」が分かれているように、ドリフトの入り方は車ごとに違います。ENTRY を上げるとコマンドの立ち上がり・グリップの抜け・車体を回す力がまとめて鋭くなり（切った瞬間に一気に曲がる）、下げると荷重移動でじわりと入る穏やかな進入になります。既定は 0（最も穏やか。実走フィードバックで「滑りがかなり良くなった」と評価された値）です。
- アクセル、ブレーキ、壁、路面の高さは従来どおり `Car::update` 側です。壁に当たったときは速度ベクトルの外向き成分も消し、強く当たったら速度全体を落とします。接触中に車体と進行方向が大きくずれている場合は車体を進行方向へ少し回して壁に沿わせるので、横向きのまま壁を滑り続けることはありません。

`--self-test` にはドリフトの自己確認（加速→ドリフトで17度以上滑る→離すと収束する）が含まれます。`--self-test --track flow` のようにコースを指定しての確認もできます。

## Chrome 拡張機能（画面外の調整ツール）

ゲーム内フォントは英数字のみのため、調整ツールの日本語 UI は Chrome 拡張として画面外（ブラウザのツールバー側）に置いています。`extension/` フォルダが本体です。

- 導入: Chrome で `chrome://extensions` を開き、デベロッパーモードを ON にして「パッケージ化されていない拡張機能を読み込む」から、このリポジトリの `extension/` フォルダを選ぶ
- 使い方: ブラウザ版ゲームのタブを開いた状態で、ツールバーの「ドリフト調整」アイコンを開くと、全項目を日本語のスライダーで変更できる
- 仕組み: 拡張はゲームページの `localStorage`（キー `racegameDriftTuning`）を読み書きし、ゲーム側は 0.5 秒ごとに確認して変更を走行中でも取り込む。ゲーム内 T パネルと同じ値・同じ保存先なので、どちらで変えてもよい

## ブラウザ版

```bash
emcmake cmake -B build
cmake --build build
python3 -m http.server 8080
```

`http://localhost:8080/build/racegame.html`

## Linux 版

```bash
cmake -B build-native
cmake --build build-native
./build-native/racegame
```

画面は `http://localhost:6080`（パスワード `vscode`）です。コンテナ内では音は鳴りません。

ロジックだけの確認:

```bash
./build-native/racegame --self-test
```
