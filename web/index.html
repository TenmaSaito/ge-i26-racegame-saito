操作
W / ↑：アクセル　S / ↓：ブレーキ　A・D：ステアリング
ドリフト：Space（または Shift / Ctrl）を押しながら A・D ／ 矢印キーを右スティック代わりに使うツインスティック方式も可
ドリフト中はマウスを横に動かすと、ドリフト開始位置からのずれで角度を調整できます
ゲームパッド対応：左スティック＝ステア、右スティック＝ドリフト、B / LB / RB＝ドリフト、RT / LT＝アクセル / ブレーキ（ブラウザではパッドのボタンを一度押すと認識されます。認識状態は下のデバッグ欄の PAD に表示）
1 / 2 / 3：車種切替（BALANCE / DRIFT / SPEED）　C：カメラ（CHASE / CLOSE / FAR / DRIVER）
T：ドリフト調整パネル　R：リセット　P：一時停止　F：全画面（切替）
タイトル画面で Enter / クリック / パッド START でスタート。3 周走るとゴール（リザルト画面）になります
ドリフトのデバッグ情報は、ゲーム画面の下のパネルに表示されます
